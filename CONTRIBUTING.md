# Contributing to LibreConnect

First of all, thank you for your interest in contributing to LibreConnect! We welcome any form of help, whether it's reporting bugs, suggesting new features, or submitting code changes.

LibreConnect is an open-source project that aims to create a private, seamless ecosystem between all your devices. Your contributions help make this goal a reality.

---

## How to Contribute

### Reporting Issues
If you encounter a bug or have a suggestion, please open an issue on our [GitHub Issues](https://github.com/ppaluchowski64/LibreConnect/issues) page. When reporting a bug, please include:
- A clear and descriptive title.
- Steps to reproduce the issue.
- Your operating system and device information.
- Relevant log files or screenshots.

### Submitting Pull Requests
We love pull requests! To contribute code:
1. Fork the repository.
2. Create a new branch for your feature or bugfix.
3. Ensure your code follows the existing style and conventions.
4. Submit a Pull Request with a clear description of your changes.

## Gathering Logs

To help us diagnose issues, providing application logs is extremely helpful.

### Desktop (Windows, Linux, macOS)
Logs are stored in the application's data directory, which varies by operating system:
- **Windows:** `%LOCALAPPDATA%\LibreConnect\LibreConnect\logs\`
- **Linux:** `~/.local/share/LibreConnect/LibreConnect/logs/`
- **macOS:** `~/Library/Application Support/LibreConnect/LibreConnect/logs/`

Within these directories, you will find `all/` (complete logs) and `errors/` (filtered error logs) subdirectories.

### Android
Logs on Android are stored in the application's public data folder (typically `/Android/data/com.LibreConnect.mobile/files/`). While this folder is technically "public", most commercial Android distributions restrict direct access to it via on-device file managers. You can access it by connecting your device to a computer via USB, but we've implemented a much easier shortcut:

1. Open the LibreConnect mobile application.
2. **Tap the logo 5 times** (available on almost every screen).
3. The Android Share menu will appear with the logs prepared for export.
4. You can share them via any supported app, but we recommend using the **LibreConnect Share Provider** ("Send to download folder"). This will send the logs directly to the download folder configured on your paired computer (requires the desktop app to be running).

## Environment Setup

LibreConnect uses a specialized configuration script to manage its multi-platform build environment.

### Prerequisites
Before you begin, ensure you have the following installed:
- **Python 3.x**
- **CMake** (3.20 or newer)
- **Conan** (2.x)
- **Qt 6.8.x** (with required modules like Multimedia and Quick)
- **Ninja** (recommended generator)
- **Android NDK & SDK** (only if building for Android)

### Configuration
1. Clone the repository:
   ```bash
   git clone https://github.com/ppaluchowski64/LibreConnect.git
   cd LibreConnect
   ```
2. Run the configuration script for the first time:
   ```bash
   python configure_project.py
   ```
   This will generate a `.env` file in the root directory.
3. Open the `.env` file and fill in the required paths and settings:
   - `BUILD_FOR`: Target platform (`Desktop`, `Android`, or `All`).
   - `QT_DIR_DESKTOP` / `QT_DIR_ANDROID`: Paths to your Qt installations.
   - `ANDROID_NDK_DIR` / `ANDROID_SDK_DIR`: Paths for Android development.
   - `DISABLE_DEBUG`: Set to `false` for development builds.
4. Run the script again to install dependencies via Conan and prepare the build directory:
   ```bash
   python configure_project.py
   ```

## Building the Project

LibreConnect uses CMake with presets generated by Conan.

### Desktop (Windows, Linux, macOS)
By default, the project is configured for a debug build to facilitate development.
```bash
cmake --preset conan-debug    # Default development build
# cmake --preset conan-release  # Use for release builds
cmake --build --preset conan-debug
```

### Android
For Android, the project requires a two-step process:
1. Run `python configure_project.py` with `BUILD_FOR=Android` set in your `.env`. This script automatically configures the NDK toolchain and installs necessary C++ dependencies via Conan.
2. Build the project using CMake with the Android-specific presets:
   ```bash
   cmake --preset conan-release
   cmake --build --preset conan-release
   ```
   The final APK will be generated within the build directory.

## Project Structure

LibreConnect follows a modular architecture. Below are the primary directories you should be aware of:

- **`utilities/`**: Core system-level abstractions, P2P network components, and low-level libraries used by the rest of the application.
- **`android/`**: Android-specific native code and Kotlin integrations that interface directly with the Android system APIs.
- **`modules/`**: High-level feature implementations (e.g., file sharing, notification sync). Features are modularized into logic shared between platforms and platform-specific implementations.
- **`daemon/`**: The background process for desktop platforms responsible for managing device communication and feature execution.
- **`apps/`**: The main application entry points for `desktop` (Qt/QML) and `mobile` (Qt/Android).
- **`tests/`**: Comprehensive suite of unit and integration tests for various components.

## Continuous Integration (CI)

We use **GitHub Actions** to automate our build process across all supported platforms. Our CI environment uses the following compilers:
- **Windows:** MSVC
- **Linux:** GCC
- **macOS:** Clang (Apple Silicon)
- **Android:** Clang (NDK toolchain)

Please ensure your changes pass the CI checks before requesting a review.
